

# 📄 需求分析文档

## 《金币地鼠大作战》游戏需求规格说明书

---

### 1. 项目概述

| 项目 | 内容 |
|------|------|
| **游戏名称** | 金币地鼠大作战 |
| **游戏类型** | 休闲益智 / 双机制混合（接物 + 打靶） |
| **目标平台** | Web 浏览器（PC + 移动端触屏） |
| **技术栈** | HTML5 + CSS3 + JavaScript (Canvas 2D) |
| **开发周期** | 30 分钟（原型） |
| **风格定位** | Q版卡通、色彩明亮、轻松可爱 |

---

### 2. 核心玩法

游戏融合了 **"接金币"** 和 **"打地鼠"** 两种经典玩法：

| 机制 | 描述 |
|------|------|
| **接金币** | 金币从屏幕顶部随机位置下落，玩家移动底部篮子接住金币获得分数 |
| **打地鼠** | 地鼠从底部固定洞位随机冒出，玩家点击地鼠可获得额外分数 |
| **地鼠偷金币** | 地鼠出现后若 1.5 秒内未被点击，会随机吃掉场上一个金币（惩罚机制） |

---

### 3. 游戏规则

#### 3.1 基础规则

| 规则项 | 说明 |
|--------|------|
| 游戏时长 | 45 秒 |
| 胜利条件 | 时间结束后，总分最高（无失败条件） |
| 总分计算 | `总分 = 金币得分 + 地鼠击打数 × 2` |

#### 3.2 金币规则

| 规则项 | 说明 |
|--------|------|
| 生成方式 | 自动从顶部随机 x 位置生成 |
| 生成间隔 | 约 0.9 秒/个 |
| 最大数量 | 同时最多 6 个 |
| 下落速度 | 随机 1.2 ~ 2.4 像素/帧 |
| 得分条件 | 篮子接住 → `+1` 分 |
| 消失条件 | 掉到底部 → 消失，**不扣分** |
| 被吃条件 | 地鼠存活满 1.5 秒 → 随机吃掉 1 个金币 |

#### 3.3 地鼠规则

| 规则项 | 说明 |
|--------|------|
| 生成方式 | 从底部 5 个固定洞位随机冒出 |
| 生成间隔 | 约 2.2 秒/只 |
| 最大数量 | 同时最多 2 只 |
| 存活时长 | 1.5 秒（倒计时） |
| 被点击 | 地鼠消失，`🔨 +1`（计入总分倍数） |
| 未被点击 | 1.5 秒后地鼠消失，**随机吃掉 1 个金币** |
| 无金币可吃 | 地鼠消失，无任何效果 |

#### 3.4 篮子规则

| 规则项 | 说明 |
|--------|------|
| 控制方式 | 鼠标移动 / 手指滑动（触屏） |
| 位置限制 | 水平移动，不能超出画布边界 |
| 碰撞检测 | 矩形（篮子）与圆形（金币）碰撞检测 |

### 5. 交互设计

| 交互方式 | 触发条件 | 响应 |
|----------|----------|------|
| 鼠标移动 | 在画布上移动鼠标 | 篮子跟随水平移动 |
| 手指滑动 | 在触屏上滑动 | 篮子跟随水平移动 |
| 鼠标点击 | 点击地鼠 | 地鼠消失，`🔨 +1`，播放打击特效 |
| 手指点击 | 点击地鼠 | 同上（触屏适配） |
| 按钮点击 | 点击「开始」 | 启动游戏 / 重新开始 |
| 按钮点击 | 点击「重来」 | 重置所有状态到初始 |

### 7. 数据模型

```javascript
// 游戏主状态
state = {
  score: 0,           // 金币得分
  hits: 0,            // 击打地鼠数
  timeLeft: 45,       // 剩余秒数
  active: false,      // 是否进行中
  ended: false,       // 是否已结束
  coins: [],          // 金币数组
  moles: [],          // 地鼠数组
  basket: { x: 250 }  // 篮子位置
}

// 金币对象
coin = {
  x, y,               // 位置
  radius: 20,         // 半径
  speed: 1.2~2.4      // 下落速度
}

// 地鼠对象
mole = {
  x, y,               // 位置（由洞位决定）
  radius: 32,         // 半径
  timer: 1.5,         // 剩余存活秒数
  holeIndex: 0~4      // 洞位索引
}
```

### 8. 技术规格

| 项目 | 规格 |
|------|------|
| 画布尺寸 | 500 × 500 像素（逻辑） |
| 渲染方式 | Canvas 2D (60fps) |
| 游戏循环 | `requestAnimationFrame` |
| 计时方式 | `setInterval` (1秒) + Delta Time |
| 碰撞检测 | 矩形 ↔ 圆形（接金币），点 ↔ 圆形（打地鼠） |
| 响应式 | 画布 CSS 自适应，触屏 + 鼠标双支持 |
| 外部依赖 | 无（纯原生） |

---

### 9. 边界与异常处理

| 场景 | 处理方式 |
|------|----------|
| 金币掉到底部 | 从数组中移除，不扣分 |
| 地鼠出现时无金币 | 1.5 秒后正常消失，不吃金币 |
| 同时生成地鼠占洞 | 检测已占用洞位，分配到空闲洞位 |
| 所有洞位被占 | 暂不生成新地鼠 |
| 金币达到上限 | 暂停生成新金币 |
| 游戏结束时仍有活动元素 | 停止所有循环，清理定时器 |
| 触屏与鼠标同时操作 | 两者兼容，互不干扰 |
| 窗口大小变化 | 篮子位置自动修正边界 |

### 10. 可调参数（配置化）

所有核心参数集中在 `CONFIG` 对象中，便于调整平衡性：

```javascript
CONFIG = {
  GAME_DURATION: 45,           // 游戏秒数
  MAX_COINS: 6,                // 最大金币数
  COIN_RADIUS: 20,             // 金币大小
  COIN_SPEED: 1.8,             // 基础下落速度
  MOLE_RADIUS: 32,             // 地鼠大小
  MOLE_DURATION: 1.5,          // 地鼠存活秒数
  MOLE_MAX: 2,                 // 最大地鼠数
  BASKET_WIDTH: 90,            // 篮子宽度
  HOLE_COUNT: 5,               // 洞位数量
  SPAWN_COIN_INTERVAL: 0.9,    // 金币生成间隔
  SPAWN_MOLE_INTERVAL: 2.2,    // 地鼠生成间隔
}
```
